# Выбор вида облигации

## Область применения

Скилл применяется при подборе облигаций, когда пользователь называет вид
облигации. Вид задаётся фильтром `bondtype43` — массивом целых чисел;
названия видов строками не передавай.

## Виды облигаций

| ID | Вид в скринере |
| --- | --- |
| 1 | Амортизируемая облигация |
| 2 | Валютная облигация |
| 3 | Дисконтная облигация |
| 4 | Конвертируемая облигация |
| 5 | Линкер / облигация с индексируемым номиналом |
| 6 | Облигация с плавающим купоном |
| 7 | Облигация с фиксированным (известным) купоном |
| 8 | Облигация с фиксированным (неизвестным) купоном |
| 9 | Структурная облигация |

## Соответствия формулировок

- «амортизируемые», «с амортизацией долга» → `bondtype43: [1]`
- «валютные», «номинал в валюте» → `[2]`
- «дисконтные», «бескупонные», «с нулевым купоном» → `[3]`
- «конвертируемые» → `[4]`
- «линкеры», «с индексируемым номиналом», «инфляционные» → `[5]`
- «флоатеры», «плавающий купон», «переменный купон», «плавающая ставка» → `[6]`
- «фиксированный известный», «постоянный известный купон» → `[7]`
- «фиксированный неизвестный», «ставка купона не объявлена» → `[8]`
- «структурные», «структурные облигации» → `[9]`

## Фиксированный купон

- «Фиксированный купон» без уточнения → `[7]`: принятое в сервисе значение
  известного фиксированного купона.
- «Фиксированный неизвестный», «ставка купона не объявлена» → `[8]`.

## Логика И/ИЛИ

- Несколько значений в одном фильтре — ИЛИ: `[6, 7]` означает флоатеры или
  бумаги с фиксированным купоном.
- У выпуска один вид, поэтому пересечение двух видов через `bondtype43` не
  выражается. Если пользователь требует оба вида, уточни, какой признак важнее.

## Неизвестные и неоднозначные виды

- Если вида нет в таблице («субординированные», «ипотечные» и т.п.),
  не подбирай приблизительный ID: уточни запрос или объясни, что такого
  фильтра в скринере нет.
- Если формулировка допускает несколько видов, уточни, какой нужен.

## Уточнение сложных и граничных случаев - 

- **Дисконтные ценные бумаги (ID 3):** Применяется ТОЛЬКО если пользователь ищет бескупонные облигации 
  (zero-coupon) по конструкции выпуска. Если пользователь просит «купить облигации с дисконтом к номиналу»
  (имея в виду рыночную цену &lt; 100%), не применяй `bondtype43: [31]`, а уточняй критерий цены. 
- **Пошаговый купон и оферты (ID 8):** Формулировки «step-up», «пошаговый купон», «купон меняется после оферты», 
  «ставки купонов на будущие периоды не определены» → `bondtype43: [43]`. 
- **Запросы по отсутствующим характеристикам:** - Если пользователь ищет «субординированные», 
  «вечные/перпетуальные», «отзывные/с офертой» (callable/putable), «ипотечные/MBS»: сообщи, что данный 
  признак не входит в категорию видов `bondtype43`, и предложи найти бумаги по доступным фильтрам. 
- **Обработка комбинаций параметров:** - При запросе гибридных видов (например, «валютный флоатер» 
  или «амортизируемый линкер»): напомни пользователю, что параметр вида принимает одно значение, и уточни, 
  какой критерий приоритетен для поиска.

## Примеры

Пользователь: «Подбери флоатеры»

```json
{"intent":"tool","tool":"search_bonds","args":{"bondtype43":[6]}}
```

Пользователь: «Амортизируемые облигации»

```json
{"intent":"tool","tool":"search_bonds","args":{"bondtype43":[1]}}
```

Пользователь: «Дисконтные или бескупонные облигации»

```json
{"intent":"tool","tool":"search_bonds","args":{"bondtype43":[3]}}
```

Пользователь: «Облигации с фиксированным известным купоном»

```json
{"intent":"tool","tool":"search_bonds","args":{"bondtype43":[7]}}
```

Пользователь: «Облигации с фиксированным неизвестным купоном»

```json
{"intent":"tool","tool":"search_bonds","args":{"bondtype43":[8]}}
```

Пользователь: «Линкеры или инфляционные облигации»

```json
{"intent":"tool","tool":"search_bonds","args":{"bondtype43":[5]}}
```

Пользователь: «Конвертируемые или структурные облигации»

```json
{"intent":"tool","tool":"search_bonds","args":{"bondtype43":[4,9]}}
```

Пользователь: «Флоатеры или фиксированный купон»

```json
{"intent":"tool","tool":"search_bonds","args":{"bondtype43":[6,7]}}
```
