# Выбор фильтра по рейтингу

## Область применения

Скилл применяется при подборе облигаций, когда пользователь задаёт кредитный
рейтинг. В BondsScreener используется одна национальная шкала; агентство
или отдельную шкалу не выбирай. Фильтр задаётся двумя полями:

- `rating_min` — рейтинг X и все более высокие по качеству («не ниже X»);
- `rating_max` — рейтинг X и все более низкие по качеству («не выше X»).

Оба поля принимают только канонические значения шкалы строками.

## Шкала рейтингов

| Позиция | Рейтинг |
| --- | --- |
| 1 | AAA |
| 2 | AA+ |
| 3 | AA |
| 4 | AA- |
| 5 | A+ |
| 6 | A |
| 7 | A- |
| 8 | BBB+ |
| 9 | BBB |
| 10 | BBB- |
| 11 | BB+ |
| 12 | BB |
| 13 | BB- |
| 14 | B+ |
| 15 | B |
| 16 | B- |
| 17 | CCC+ |
| 18 | CCC |
| 19 | CCC- |
| 20 | CC |
| 21 | C |
| 22 | D |

`BBB-` и выше — инвестиционный уровень; `BB+` и ниже — спекулятивный.

## Соответствия формулировок

- «не ниже X», «X и выше», «не хуже X» → `rating_min: "X"`.
- «не выше X», «X и ниже» → `rating_max: "X"`.
- «ровно X», «только X» → `rating_min: "X"` и `rating_max: "X"`.
- «от X до Y», «диапазон X–Y», «X–Y» → `rating_min` = худший из X и Y,
  `rating_max` = лучший из X и Y; границы включительные.
- «инвестиционный уровень», «инвестиционный рейтинг» → `rating_min: "BBB-"`.
- «спекулятивный уровень», «мусорные облигации», «high yield» →
  `rating_max: "BB+"`.
- «любой рейтинг», «рейтинг не важен» → не передавай `rating_min` и `rating_max`.

## Границы и диапазон

- `rating_min` и `rating_max` включительные.
- В диапазоне `rating_min` — худший рейтинг (нижняя граница качества),
  `rating_max` — лучший (верхняя граница качества); не путай с порядком «от/до».
- «ровно X» — обе границы равны X.
- «от X до Y» — сначала определи лучший и худший рейтинг по таблице;
  `rating_min` = худший, `rating_max` = лучший.
- «строго выше X» → `rating_min` = следующая более высокая ступень;
  «строго ниже X» → `rating_max` = следующая более низкая ступень.
  Если ступени нет (выше AAA или ниже D), уточни.
- Один фильтр задаёт непрерывный диапазон. Набор несмежных рейтингов
  («AAA или BB») через `rating_min`/`rating_max` не выражается без
  промежуточных значений: уточни, какой диапазон или одна ступень нужны.
- «Строго выше AAA» — наивысшая ступень шкалы уже достигнута. Сгенерировать фильтр невозможно. 
  Верни intent="ask" с объяснением, что AAA — это максимальный рейтинг национальной шкалы.
- «Строго ниже D» — наинизшая ступень шкалы (дефолт) уже достигнута. Верни intent="ask" с объяснением, 
  что D — минимальный рейтинг.

## Неизвестные и неоднозначные рейтинги

- Приводи обозначение к каноническому виду: верхний регистр, без пробелов;
  суффиксы `(RU)`, `ru`, `.ru`, `.SF` отбрасывай, сохраняя `+` и `-`.
  «AA(RU)» → «AA», «ruBBB+» → «BBB+».
- Не теряй `+`/`-` и не округляй рейтинг до категории: `AA-`, `AA`, `AA+` —
  разные значения.
- Рейтинг вне шкалы («AAA+», «AAA-», «A1») не подбирай приблизительно: уточни.
- «С рейтингом X» без направления неоднозначно: уточни, нужен только X или
  X и выше.
- «Выше X» и «ниже X» без «или равно» неоднозначны: уточни, нужна строгая
  граница (следующая ступень) или включительная «X и выше/ниже».
- «Без рейтинга», «нет рейтинга» фильтром не выражается: `rating_min` и
  `rating_max` отбирают только бумаги с непустым рейтингом. Объясни
  ограничение и спроси, искать ли без этого условия.
- «Надёжные», «самые надёжные», «качественные» — не рейтинг; не подставляй
  AAA. Уточни минимальный рейтинг.
- Агентство не является отдельным фильтром: «АКРА AA» и «Эксперт РА BBB+»
  используй как «AA» и «BBB+», но не обещай выбор конкретного агентства.

## Примеры

Пользователь: «Не ниже BBB»

```json
{"intent":"tool","tool":"search_bonds","args":{"rating_min":"BBB"}}
```

Пользователь: «Не выше A-»

```json
{"intent":"tool","tool":"search_bonds","args":{"rating_max":"A-"}}
```

Пользователь: «Ровно AA»

```json
{"intent":"tool","tool":"search_bonds","args":{"rating_min":"AA","rating_max":"AA"}}
```

Пользователь: «От AA до BBB»

```json
{"intent":"tool","tool":"search_bonds","args":{"rating_min":"BBB","rating_max":"AA"}}
```

Пользователь: «BBB и выше»

```json
{"intent":"tool","tool":"search_bonds","args":{"rating_min":"BBB"}}
```

Пользователь: «BB и ниже»

```json
{"intent":"tool","tool":"search_bonds","args":{"rating_max":"BB"}}
```

Пользователь: «Инвестиционный уровень»

```json
{"intent":"tool","tool":"search_bonds","args":{"rating_min":"BBB-"}}
```

Пользователь: «Спекулятивные облигации»

```json
{"intent":"tool","tool":"search_bonds","args":{"rating_max":"BB+"}}
```

Пользователь: «Строго выше BBB»

```json
{"intent":"tool","tool":"search_bonds","args":{"rating_min":"BBB+"}}
```

Пользователь: «Строго ниже BBB»

```json
{"intent":"tool","tool":"search_bonds","args":{"rating_max":"BB+"}}
```

Пользователь: «Не ниже AA(RU)»

```json
{"intent":"tool","tool":"search_bonds","args":{"rating_min":"AA"}}
```

Пользователь: «строго выше AAA»

```json
{
  "intent": "ask",
  "question": "Рейтинг AAA является максимальным в национальной шкале. Уточните критерий: искать облигации с рейтингом ровно AAA?",
  "missing_filters": []
}
```

Пользователь: «строго ниже D»

```json
{
  "intent": "ask",
  "question": "Рейтинг D является минимальным (дефолтным) в национальной шкале. Качественно более низких ступеней нет. Какой диапазон рейтингов рассмотреть?",
  "missing_filters": []
}
```
