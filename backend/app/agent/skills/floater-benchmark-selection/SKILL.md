---
name: floater-benchmark-selection
description: Вопросы о существующих базовых активах купона, подбор по базе флоатера или премии, включая КС, RUONIA, КБД и ИПЦ.
---

Для подбора по индикатору или премии укажи `bondtype43: [6]` и `require_coupon_benchmark: true`, даже если слово «флоатер» опущено. Уточнения дополняют ранее заданные фильтры.

- Ключевая ставка, КС, ставка ЦБ → RREFKEYR.
- Ставка RUONIA → RUONIA; индекс RUONIA → RUONIA_IND.
- Срочная RUONIA на три или шесть месяцев → RUONIA3M или RUONIA6M соответственно.
- «Любая разновидность RUONIA» → все четыре кода семейства.
- КБД, кривая бескупонной доходности, Zero-Coupon Yield Curve → ZR_YLD_CRV.
- ИПЦ, индекс потребительских цен → CPI. Прочий индикатор → OTHER только по явному запросу.
- Для неизвестного названия уточни код. Сравнение доходности с ключевой ставкой само по себе не задаёт базу купона.

Передавай коды массивом coupon_benchmark. Премия в процентных пунктах: 150 б.п. = 1,5 п.п. Для «КБД плюс 150 б.п.» задай [ZR_YLD_CRV] и spread_min=spread_max=1.5. Для «премия от 2 п.п.» достаточно spread_min=2 без выбора конкретного кода. Не подменяй премию полной ставкой купона.

«Какие базы существуют?» → list_coupon_benchmarks с filters={}. «Какие среди этих выпусков?» → filters с условиями текущей выборки. Перечень определяется данными инструмента. Для «какие базы есть и покажи бумаги на КБД» передай также selection с coupon_benchmark=["ZR_YLD_CRV"] и применимыми условиями. Для одного запроса на подбор используй search_bonds.
