# Правила агента

Системные инструкции хранятся здесь в Markdown, отдельно от Python-кода.

- `common.md` добавляется к системному сообщению каждого этапа: селектора,
  роутера и финализатора.
- Файл этапа добавляется вместе с общими правилами: `router.md`, `finalizer.md`
  или `skill-selection.md`.
- Тексты исправления JSON загружаются из `*-json-repair.md` модулем сборки промптов.
- Если обязательный файл отсутствует или пуст, загрузчик сообщает об ошибке;
  приложение не запускает модель с неполным набором правил.

Не помещайте сюда инструкции одного узкого сценария: такие инструкции относятся
к `../skills/<skill-name>/SKILL.md` и загружаются после выбора скила моделью.
