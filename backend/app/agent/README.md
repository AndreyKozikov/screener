# Архитектура агента

```text
agent/
├── rules/                 # системные правила, загружаются для каждого этапа
├── skills/                # узкие навыки, тело загружается после выбора LLM
├── rule_loader.py         # чтение правил по этапу
├── skill_loader.py        # каталог метаданных и отложенная загрузка навыков
└── prompts.py             # сборка сообщений из правил, каталога инструментов и навыков
```

Правила задают неизменяемое поведение агента и всегда передаются модели вместе
с общими правилами. Для выбора скилов модель получает только `name` и
`description` из YAML frontmatter. Полное тело `SKILL.md` и его ссылки из
`references/` добавляются к роутеру только для скилов, которые выбрал селектор.

Каталог `skills/` следует формату Agent Skills: один скил на папку,
`SKILL.md` с YAML frontmatter (`name`, `description`) и инструкциями в Markdown.
